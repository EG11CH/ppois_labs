# Запуск готовых программ на Linux x86-64

Откройте терминал в этой папке и запустите одну из программ:

```bash
./dictionary_cli
./set_cli
```

Обе программы собраны статически для Linux x86-64. Для запуска не нужны
IDE, компилятор, Catch2 и динамические библиотеки C++. Для ARM/aarch64
нужна сборка из исходников на соответствующей архитектуре.

В меню номер вводится отдельной строкой. `0` — выход.
Словарь: `1` добавить слово, `3` найти перевод, `4` заменить, `7` загрузить файл.
Для загрузки примера укажите `examples/dictionary.txt`. `8` сохраняет словарь.
Данные файлов и сообщения записаны в UTF-8.

Множество: `1` задаёт A, `2` задаёт B. Введите, например, `{a, b, {c}, {}}`.
`8`, `9`, `10` изменяют A объединением, пересечением и разностью с B.
`11` показывает булеан; по умолчанию разрешено до 4096 подмножеств.

Сгенерированная документация Doxygen: `documentation/index.html`.
Её можно открыть браузером без подключения к сети.
