# Соответствие требованиям первой лабораторной

Пункты относятся к `lab1.md`, `common_requirements.md` и `checklist.md`,
предоставленным вместе с заданием. Требования к лабораторным 2–4
не переносятся на первую работу.

| Требование | Реализация/проверка |
|---|---|
| C++ | Стандарт C++17, консольная сборка CMake/GCC |
| Словарь на двоичном дереве поиска | Собственный `Node`, `root_`, поиск по английскому ключу |
| `+=` для std::string и char* | Перегрузки `Entry`, `CStringEntry`, `MutableCStringEntry` |
| Удаление, чтение/замена через `[]`, количество, загрузка | `-=`, две версии `[]`, `size`, `loadFromFile` |
| Вложенные множества и отсутствие повторов | `SetElement` с глубокой копией вложенного `Set`; `add` проверяет принадлежность |
| Пустота, мощность, принадлежность, добавление/удаление | `empty`, `size`, `[]`, `add`, `remove` |
| Все операции множеств и составные операторы | `+`, `+=`, `*`, `*=`, `-`, `-=` |
| Булеан | `powerSet`, включая пустое и исходное множество |
| Формирование из строки | Рекурсивный разбор, в том числе примера из варианта 1.4.1 |
| Инкапсуляция | Все поля private, изменяемые внутренние коллекции не возвращаются |
| Разделение интерфейса/реализации | Публичные объявления `.h`, реализации `.cpp` |
| Независимость от UI | Классы не используют cin/cout; меню принимают объекты и потоки |
| Копирование и присваивание | Глубокие копии дерева и вложенных множеств, отдельные тесты |
| Освобождение ресурсов | RAII: unique_ptr, vector; словарь освобождается итеративно |
| Сравнение | `==`, `!=`, без зависимости от дерева/порядка элементов |
| Текст и потоки | Словарь и Set: `<<`, `>>`; SetElement: `fromString`, `<<` |
| Отдельные консольные меню | `dictionary_cli`, `set_cli` со всеми ключевыми операциями |
| Модульные тесты из консоли | Catch2 через CTest, дополнительные сценарии ввода и запуск бинарников |
| Покрытие строго >90% | gcovr и скрипт, который проверяет именно `> 90`, а не `>= 90` |
| Doxygen | Комментарии API, конфигурация и реально генерируемый HTML |
| Качество кода | Именованные лимиты, единый стиль, короткие функции, GCC с предупреждениями как ошибками, Cppcheck |
| Один репозиторий, папки lab1–lab4 | Структура подготовлена для существующего общего репозитория |
| Сборочные артефакты исключены из git | Отдельные build/release, правила игнорирования |
| Feature-ветка, PR и одобрение | Описан порядок действий; фактическое выполнение требует ссылки и доступа к репозиторию |
| CI и проверяемый Releases-артефакт | Workflow подготовлен, локальная статическая сборка и упаковка предусмотрены |

Наличие конфигурации CI не подтверждает удалённый успешный запуск.
Точные результаты выполненных проверок приведены в отдельном отчёте проверки.
Одобрение преподавателя, защита, доступность репозитория преподавателю и
проверка на плагиат подтверждаются вне локальной сборки и здесь не заявляются
выполненными. Мини-лекция относится к завершению всего курса, а не только `lab1`.
