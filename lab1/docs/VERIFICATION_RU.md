## Воспроизведение

Используйте новую папку сборки, чтобы старые счётчики не влияли на результат:

```bash
cmake -S . -B build-fresh -DCMAKE_BUILD_TYPE=Debug -DENABLE_COVERAGE=ON
cmake --build build-fresh --parallel 2
ctest --test-dir build-fresh --output-on-failure
python3 lab1/tools/check_coverage.py build-fresh
cmake --build build-fresh --target docs
```

Для измерения покрытия нужен gcov той же версии GCC, которой выполнена сборка.
В разных версиях компилятора число исполняемых строк может немного отличаться;
CI заново измеряет результат и требует строго больше 90%.
