# Лабораторная №1: классы словаря и множества

Реализованы варианты **1.2 «Англо-русский словарь»** и **1.4.1 «Множество»**
на C++17. Это две программы с независимыми меню и общей системой сборки.

## Англо-русский словарь

`EnglishRussianDictionary` использует собственные узлы двоичного дерева
поиска. Каждый узел содержит пару строк и двух потомков. В левом поддереве
ключи меньше текущего английского слова, в правом — больше. `std::map`
не используется. Дерево не балансируется, поэтому в худшем случае поиск,
добавление и удаление занимают O(n), в обычном сбалансированном дереве — O(log n).

| Операция | Пример C++ | Поведение |
|---|---|---|
| Добавление std::string | `dictionary += Dictionary::Entry{"cat", "кот"};` | Новая пара в дереве |
| Добавление C-строк | `dictionary += Dictionary::CStringEntry{"dog", "собака"};` | Содержимое строк копируется |
| Добавление char* | `dictionary += std::make_pair(word, translation);` | Отдельная перегрузка для изменяемых массивов char |
| Удаление | `dictionary -= "cat";` | Удаляет узел; отсутствующий ключ ничего не меняет |
| Чтение перевода | `dictionary["dog"]` | Ссылка на перевод существующего слова |
| Замена перевода | `dictionary["dog"] = "пёс";` | Ключ и количество не меняются |
| Количество | `dictionary.size()` | Число пар, O(1) |
| Загрузка файла | `dictionary.loadFromFile(path)` | Полная замена только после успешной проверки |

В таблице `Dictionary` означает псевдоним
`using Dictionary = lab1::EnglishRussianDictionary;`.
Примеры используют явно названные типы пар, чтобы выбор перегрузки `+=`
был однозначным. Для C-строк есть `const char*` и `char*`.

Правила: ключ не может быть пустым; повторный ключ вызывает
`std::invalid_argument`; `nullptr` для C-строк запрещён; отсутствующий ключ
в `[]` вызывает `std::out_of_range`. Регистр учитывается: `Cat` и `cat`
различаются. Пустой перевод допустим, в том числе при замене через `[]`.
Копирование создаёт отдельные узлы, равенство сравнивает пары независимо
от формы дерева. Освобождение дерева и его обходы сделаны без рекурсии.

Формат UTF-8-файла:

```text
2
"cat" "кот"
"ice cream" "мороженое"
```

Первая строка — количество пар, далее обязательно две строки в двойных
кавычках на каждую пару. Разделитель — пробельные символы; запись по одной
паре на строке удобна для чтения. Кавычки и обратная косая черта внутри
строки экранируются `\"` и `\\`. Лимит загрузки — 1 000 000 пар, это именованная
константа `maxFileEntries`. Ошибочный файл и лишние данные после объекта
не меняют существующий словарь. Потоковый `>>` читает один объект, позволяя
последовательно читать несколько словарей из одного потока.

## Канторовское множество

`Set` хранит значения `SetElement`. Элемент — непустой строковый атом
или другое множество. Вложенное множество копируется глубоко и доступно
только для чтения, чтобы изменение извне не создавало дубликаты.
Внутренний `std::vector` не выставляется наружу.

```cpp
const lab1::Set first = lab1::Set::fromString("{a, b, {a, b}, {}}");
const lab1::Set second = lab1::Set::fromString("{{b, a}, b, c}");
const lab1::Set united = first + second;
const lab1::Set common = first * second;
const lab1::Set remaining = first - second;
const lab1::Set subsets = first.powerSet();
```

| Операция | Назначение |
|---|---|
| `empty()`, `size()` | Пустота и мощность |
| `add(element)`, `remove(element)` | Добавление/удаление; возвращают факт изменения |
| `set[element]` | Проверка принадлежности, результат bool |
| `+`, `+=` | Объединение |
| `*`, `*=` | Пересечение |
| `-`, `-=` | Разность |
| `powerSet(maxSubsets)` | Все подмножества как элементы нового множества |
| `==`, `!=` | Равенство без учёта порядка, включая вложенные множества |
| `fromString`, `<<`, `>>` | Разбор текста, запись и чтение объекта |

В `{a, a, {a, b}, {b, a}}` останутся два элемента: `a` и `{a, b}`.
`{}` — пустое множество, `{{}}` содержит один элемент — пустое множество.
Атом `"{a}"` отличается от вложенного множества `{a}`.
Атомы с пробелами, запятыми, кавычками, фигурными скобками или обратной
косой чертой записываются в двойных кавычках; обычные атомы можно писать без них.
Пустой строковый атом запрещён; пустое множество разрешено.

`fromString` проверяет всю строку; `>>` читает один объект из потока.
При синтаксической ошибке `fromString` бросает `std::invalid_argument`,
а `>>` устанавливает `failbit`, сохраняя прежнее множество. При записи
элементы сортируются по текстовому представлению лишь для стабильного вывода:
математические операции не учитывают порядок.

Булеан множества из n элементов имеет 2^n элементов. `powerSet` по умолчанию
ограничен 4096 подмножествами (до 12 элементов исходного множества).
Можно передать больший `maxSubsets`; переполнение проверяется до выделения
памяти, а превышение лимита вызывает `std::length_error`.
Разбор ограничен 64 уровнями фигурных скобок константой `maxParseDepth`.
Эти ограничения явно заданы для контроля расхода ресурсов.

## Сборка, тесты и документация

Команды запуска из корня репозитория:

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug -DENABLE_COVERAGE=ON
cmake --build build --parallel 2
ctest --test-dir build --output-on-failure
python3 lab1/tools/check_coverage.py build
cmake --build build --target docs
```

Производственный код измеряется целиком: классы, меню и точки входа.
В Catch2 есть модульные проверки классов и сценарии меню с потоками;
дополнительный тест запускает реальные исполняемые файлы. Это покрытие строк,
а не заявление о покрытии всех возможных состояний или всех ветвей.
Тесты и библиотека Catch2 исключены из измерения.

HTML Doxygen: `build/lab1/documentation/html/index.html`.
Отчёт gcovr: `build/coverage/index.html`.
Соответствие заданию: `docs/REQUIREMENTS.md`.
Результаты локальной проверки: `docs/VERIFICATION_RU.md`.
